# Workspace Builder — monis.rent

An interactive workspace configurator built for the monis.rent technical challenge. Pick a desk, a chair, and accessories, watch the workspace update live, then review the estimated rental cost.

**Live demo:** https://rent-workspace-sigma.vercel.app/

> Prices are mock estimates for demonstration only, not official monis.rent prices. Nothing is ordered or paid.

## Features

- **Live preview.** Layered isometric illustrations that update as soon as you change a product. Free slots show "+ add" hotspots right in the scene.
- **Products.** 2 desks, 2 chairs, plus monitors, a lamp, and a plant. Accessories share placement slots, so items never overlap (max 2 monitors).
- **Pricing.** Monthly estimate with a long-term discount for 1, 3, 6, or 12 months.
- **Checkout summary.** Items grouped by category, a price breakdown, and a "Copy Rental Summary" button.
- **Saved selections.** Your configuration is kept in localStorage across navigation and refreshes.
- **Responsive and accessible.** Works on mobile, tablet, and desktop, with keyboard support and reduced-motion support.

## Tech stack

| Technology | Why |
|---|---|
| Next.js 16 (App Router) + React 19 | Routing, static prerendering, and `next/image` for assets |
| TypeScript (strict) | Type-safe catalog, pricing, and state |
| Tailwind CSS 4 + shadcn/ui (Base UI) | Fast, consistent styling and accessible primitives (tabs, popover) |
| Zustand (`persist`) | Small global store for the configuration, saved to localStorage |
| Lucide | Icons |
| CSS transitions | All animations, with `prefers-reduced-motion` respected |
| Vitest | Unit tests for pricing, store, and preview layout |

The preview needs no 3D, canvas, or drag-and-drop: each product is a transparent SVG positioned with percentage-based CSS on a shared 1200×800 stage.

## Running the project

Requires Node.js 22+.

```bash
npm install
npm run dev        # http://localhost:3000
```

| Script | Purpose |
|---|---|
| `npm run build` / `npm start` | Production build and server |
| `npm test` | Unit tests |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript check |
| `npm run generate:preview-assets` | Regenerate the SVG artwork |

No environment variables are needed.

## How the preview works

Desks, chairs, and accessories snap to fixed slots on the stage with set layering, so the layout stays consistent at any screen size. Slot positions live in `data/preview-layout.ts`.

The artwork is **placeholder** isometric SVG generated by `scripts/generate-preview-assets.mjs`. To use final renders, replace the files in `public/products/` and update the size values in `data/catalog.ts`. See [public/products/README.md](public/products/README.md).

## MVP limitations

- **No real rental flow.** There is no backend, database, login, or payment. "Rent this setup" only opens a summary you can copy; it does not create an order.
- **Mock data.** Prices, discounts, and the 8-product catalog are made up for the demo.
- **Placeholder artwork.** The illustrations are generated SVG, not real product photos or renders. All desks share one size, and each accessory type has a fixed number of slots (2 monitors, 1 lamp, 1 plant).
- **Fixed layout.** Products cannot be dragged or freely positioned, and there is no 3D view.
- **Local storage only.** The configuration lives in your browser, so it is not shared across devices.
- **English only**, with prices in IDR.
