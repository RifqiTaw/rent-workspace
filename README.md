# Workspace Builder — monis.rent

An interactive workspace configurator built for the monis.rent technical challenge. Pick a desk, a chair, and accessories, watch the workspace update live, then review the estimated rental cost.

> Prices are mock estimates for demonstration only, not official monis.rent prices. Nothing is ordered or paid.

## Features

- **Live preview.** Layered isometric illustrations that update as soon as you change a product.
- **Products.** 2 desks, 2 chairs, plus monitors, a lamp, and a plant. Accessories share placement slots, so items never overlap (max 2 monitors).
- **Pricing.** Monthly estimate with a long-term discount for 1, 3, 6, or 12 months.
- **Checkout summary.** Items grouped by category, a price breakdown, and a "Copy Rental Summary" button.
- **Saved selections.** Your configuration is kept in localStorage across navigation and refreshes.
- **Responsive and accessible.** Works on mobile, tablet, and desktop, with keyboard support and reduced-motion support.

## Tech stack

Next.js 16 (App Router), React 19, TypeScript (strict), Tailwind CSS 4, shadcn/ui (Base UI), Zustand, Lucide, Vitest.

## Getting started

Requires Node.js 22+.

```bash
npm install
npm run dev        # http://localhost:3000
```

| Script | Purpose |
|---|---|
| `npm run build` | Production build |
| `npm test` | Unit tests (pricing, store, preview layout) |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript check |
| `npm run generate:preview-assets` | Regenerate the SVG artwork |

## How the preview works

Every product is a transparent image placed on a 1200×800 reference stage using percentage-based positions, so the scene scales with the screen. Desks, chairs, and accessories snap to fixed slots with set layering, so the layout stays consistent.

The artwork is **placeholder** isometric SVG generated by `scripts/generate-preview-assets.mjs`. To use final renders, replace the files in `public/products/` and update the size values in `data/catalog.ts`. See [public/products/README.md](public/products/README.md).
