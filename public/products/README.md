# Product artwork — PLACEHOLDER

All files in `preview/` and `thumbnails/` are temporary isometric SVG
illustrations generated by `npm run generate:preview-assets`
(`scripts/generate-preview-assets.mjs`). They are not final product renders.

- `preview/` — transparent layers for the workspace preview, authored on a
  shared 1200×800 isometric stage (`room.svg` is the backdrop).
- `thumbnails/` — square catalog images of the same objects.

To replace with final renders (e.g. transparent WebP), keep the same camera
angle and scale, then update each product's `preview` geometry in
`src/features/workspace/data/catalog.ts` and, if objects move, the slots in
`src/features/workspace/data/preview-layout.ts`.
